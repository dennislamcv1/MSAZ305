Question 3

In Step 2 of the audit, the most critical technical gap is data quality and version integrity: the 740-PDF SharePoint library holds multiple versions of the same policies (2019 and 2024 editions side by side) plus several "DRAFT" files that were never removed, so there is no single authoritative version of any policy. If the library is indexed as it stands, retrieval will surface conflicting content for the same question, and the agent could ground an answer about infection control or referral procedures on a superseded 2019 protocol or an unapproved draft, which is a patient-safety and compliance risk that prompt design cannot fix. Before RAG is built, Meridian's policy owners must clean up the library: keep one current, approved version of each policy, archive the superseded 2019 versions and the DRAFT files outside the indexed library, and tag every remaining PDF with SharePoint metadata (status = Approved, effective date, owner, review date). Recommendation: only after this clean-up, connect Azure AI Search to the library with a filter that indexes only documents marked Approved, and use SharePoint version history so future updates replace the existing file instead of adding a new copy, keeping the index a single source of truth.
